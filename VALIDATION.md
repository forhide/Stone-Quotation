## Limits and image attribution

All processing is local/offline with no API or token costs. Recognition supports COCO objects, people segmentation and face detection; other object groups use feathered detection boxes and faces use ellipses. Sky/terrain segmentation, general instance segmentation, face identity, sensitive traits and Adobe local-mask export are not implemented. Object-derived scene tags are not a complete lighting/scene taxonomy. Tone/color fingerprint suggestions are heuristics, not a trained universal artistic-style classifier. Confidence is not calibrated; real-camera/varied-object/style datasets and Adobe interoperability need further evaluation.

JPG renders supported regional/face effects. XMP is a global approximate preset and does not export semantic masks or identical Adobe pixels. Reference content/lighting remain confounded; same-scene re-encodings are not scene diversity. Composition supports centered aspect ratios only and defaults to color-only.

Installers are unsigned development builds. Native Windows/macOS install, Retina/monitor transitions, native CI, signing and Apple notarization remain unverified. The M1 missing-data correction passes structural checks; native confirmation is pending.

The recognized-person screenshot uses the NASA public-domain astronaut image supplied by scikit-image; attribution/public-domain statement: https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/_fetchers.py (astronaut function). The source NASA photo is not bundled in the app. Other screenshots use synthetic fixtures. OpenCV soccer/basketball validation photos are external test-only inputs and are not redistributed. The screenshot shows actual local recognition, not a manually supplied mock mask.
