# v0.16.0 최종 확장 빌드 성능 기록

최종 근거는 `expanded-summary.json`, `expanded-combat-1.json`, `expanded-combat-2.json`, `final-story.json`입니다. 같은 폴더의 `v0150*`, `v0160*`, `comparison.json`은 확장 전 작업 중 측정이며 최종 빌드의 비교 결과가 아닙니다.

- 실제 OpenGL 렌더링, llvmpipe 4스레드, 1280×800, VSync/프레임 제한 해제.
- 전투 2회: 각 2초 준비 후 16초 측정. 적 8마리, 8속성 대표 특수기, 구르기·화재·전리품을 함께 표시했습니다. AI 행동을 고정한 표현 부하 검사입니다.
- 전투 평균 33.28 / 38.51ms, 중앙값 28.71 / 28.74ms, p95 54.29 / 54.75ms. 각 11회 특수기와 10회 구르기가 실행됐습니다.
- 시나리오 3장면: 각 8초 중 처음 2초 제외, 실제 대사 전환 2회. 평균은 교실 26.03ms, 도서관 53.02ms, 정원 65.23ms입니다. 도서관·정원에는 최대 약 1.05초·0.79초 지연도 기록됐습니다.
- 배경 캐시는 구역·해상도 변경 때만 갱신되고, 같은 장면의 대사마다 배우를 다시 생성하지 않습니다. 효과 수와 수명은 제한됩니다.

이 환경은 CPU 4코어 제한을 렌더러와 게임이 공유합니다. 큰 지연의 원인은 측정만으로 확정하지 못했습니다. 일시적인 지연을 제외해 결과를 좋게 보정하지 않았으며, 실제 Windows/Mac의 60FPS나 이전 버전 대비 성능 향상을 주장하지 않습니다.
