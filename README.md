# Meowgnificent v0.42.0

현재 착용한 장비로 발동하는 조합을11종으로 늘리고, 쓰러진 책장 충돌과 음악·효과음을 개선한 버전이다.

- 서로 다른 장비 슬롯의 속성을 섞는 조합8종 추가: 물김·서리·연쇄 번개·확산 불씨·뿌리 발판·은빛 가시·작은 유성·회복. 가방 보유나 과거 장착 이력으로 발동하지 않는다.
- ESC 조합 안내에서 실제 착용 장비와 예시를 확인하고11종을 스크롤한다. 장착 해제 시 충전/예약 효과를 제거하며 교체로 재사용 시간을 초기화할 수 없다.
- 갈색 책장이 쓰러진 뒤에도 그림 위치에 맞는 충돌을 유지한다.
- 교실·상점·정원·보스 피아노4곡과 정돈한 효과음17종. Safari/PWA 첫 터치·복귀 오디오 재개와 설정의 ‘소리 확인’을 추가했다. 사용자의 무음/볼륨 설정은 유지한다.
- 기존 영구 연구·장비ID·저장 호환 유지. 조합 충전/회복은 형식2의 선택 필드로 저장한다.

Windows x86_64·Linux x86_64·Mac Apple Silicon arm64·Web 실행 ZIP을 제공한다.
Windows는 ZIP을 풀고 Meowgnificent.exe, Mac은 .app을 연다.
별도 설치 프로그램이나 CMD 다운로드 명령은 필요하지 않다.
웹/휴대폰: https://forhide.github.io/meow-mobile/

타이틀 왼쪽 아래 **v0.42.0**을 확인한다. 홈 화면 앱의 이전 버전이 남으면 게임 창을 모두 닫고 인터넷 연결 상태에서 다시 연다. 앱/저장소 삭제는 요구하지 않는다.
