# Meowgnificent the wizard cat — v0.1.3

Download the ZIP for your platform, extract it, and launch the game inside. No installer or CMD/PowerShell command is required.

- Windows: `Meowgnificent-v0.1.3-windows.zip`
- Linux x86_64: `Meowgnificent-v0.1.3-linux.zip`
- Web build: `Meowgnificent-v0.1.3-web.zip` (requires a web server)
- Godot source: `Meowgnificent-v0.1.3-source.zip`

SHA-256 checksums are in `Meowgnificent-v0.1.3-SHA256SUMS.txt`.

Controls: WASD/arrows to move, mouse to aim, left click/Space to cast, Enter to start/retry, Esc to pause, R to restart.

Validation: 54 source checks, 9 Linux executable checks, 9 Windows executable checks under Wine, and a Chromium Web smoke test passed. Native Windows hardware was not tested.

This branch contains only downloadable builds. Previously shared temporary-host links have been withdrawn after an unsafe download page was reported. The game does not require an MSI installer or a command to download and silently install one.
