# Meowgnificent v0.41.1

v0.41.0 이후 플레이테스트에서 발견한 접지감·상호작용·불씨 수습과 바람 특수기를 개선한 빌드다. main 병합 `d9ca046`의 게임 동작에 버전 표기와 실행 안내를 갱신한다.

- 청소 도구함과 저장 수첩/찻잔에 바닥 충돌·근접 용도 안내. 수첩 E로 저장 메뉴를 연다.
- 수습 사건의 불씨가 타이머로 함께 사라지던 문제와 물/얼음 투사체 소화를 수정했다. 각 불씨를 정리하고 남은 수를 확인한다.
- 정예 몬스터의 전용 손그림 문장, 화분/소품의 접지 그림자.
- 바람에 감싸인 닭·날갯짓·바람/깃털 퇴장. 유니크 바람 지팡이3종은 실제 용을 보내는 ‘이번엔 진짜 용!’을 쓴다. 기존 유니크 바람 마법의 위력·흡인·3파동·사거리·쿨다운은 유지한다.
- 첫 메뉴 버전 표시를 주아 PC36/모바일60과 크림 글자·자주색 바탕·외곽선/그림자로 보강했다. 업데이트 후 **v0.41.1**을 확인한다.
- 기존 음악3곡·효과음17종, 장비·영구 연구·원정 저장 호환은 유지한다.

Windows x86_64·Linux x86_64·Mac Apple Silicon arm64·Web 실행 ZIP이다.
Windows는 ZIP 전체를 새 폴더에 풀고 `Meowgnificent.exe`, Mac은 `.app`을 연다.
별도 MSI 설치나 CMD 명령은 필요하지 않다. 웹/휴대폰: https://forhide.github.io/meow-mobile/
