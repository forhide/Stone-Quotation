# Meowgnificent the wizard cat — v0.2.1

Full-body motion update and a macOS Universal build of the accident-room prototype.

Download and extract the ZIP for your platform. No Godot installation, MSI installer or terminal download command is required.

- macOS 11+ (Apple Silicon + Intel): Meowgnificent-v0.2.1-macos.zip
- Windows x86_64: Meowgnificent-v0.2.1-windows.zip
- Linux x86_64: Meowgnificent-v0.2.1-linux.zip
- Web server build: Meowgnificent-v0.2.1-web.zip
- Godot source: Meowgnificent-v0.2.1-source.zip

The Mac app has an ad-hoc signature and is not Apple-notarized. Read PLAY-MACOS.txt inside the ZIP for opening instructions. Its bundle, Universal binary and signature hashes were checked on Linux; a real Mac launch has NOT been tested.

Six full-body key poses cover idle, spell preparation, casting, miscast recoil, hurt and tucked rolling. Belly, shoulders and hat move with the walk. Casting has a short anticipation; rolling can cancel it.

Controls: WASD/arrows move; mouse aim; click/Space cast; Shift + direction roll; Enter start/retry; Esc pause; R restart. F1/F2/F3 force the next spell result.

This is one room for testing tactical comedy, not a complete multi-room run. See CHANGES.md for implementation and validation details, and Meowgnificent-v0.2.1-SHA256SUMS.txt for file hashes. Previously shared anonymous file-host links remain withdrawn.
