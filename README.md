# Meowgnificent the wizard cat — v0.3.0

Detailed library scenery, wax candle slimes, armored brooms, leather-winged bats and burning/fallen bookshelves. Shared art caches and tighter transparent bounds reduce the fixed effects benchmark draw calls by about 22%. Floor fire and impact effects now render above the background and fallen debris. The cat retains the midway proportions and full-body motion.

Download and extract into a new folder, then launch the game. No installer or terminal command is needed.

- Windows: Meowgnificent-v0.3.0-windows.zip
- macOS / Apple Silicon support: Meowgnificent-v0.3.0-macos.zip
- Linux: Meowgnificent-v0.3.0-linux.zip
- Web server build: Meowgnificent-v0.3.0-web.zip
- Godot source: Meowgnificent-v0.3.0-source.zip

Controls: WASD/arrows move; mouse aim; click/Space cast; Shift + direction roll; Enter start/retry; Esc pause; R restart. F1/F2/F3 force the next spell result.

90 source checks, 10 Windows/Wine executable checks and 10 Linux executable checks passed. Chromium Web startup/rendering/errors and Mac app/signature structure were checked. The ZIP payload hashes match the tested desktop executables. Actual Windows hardware performance and Mac runtime were not tested. Cloud software-renderer timings vary; this is not a 60 FPS guarantee. The Mac app is ad-hoc signed and not Apple-notarized; see PLAY-MACOS.txt in the ZIP.

See CHANGES.md and Meowgnificent-v0.3.0-SHA256SUMS.txt. Previously shared anonymous file-host links remain withdrawn.
