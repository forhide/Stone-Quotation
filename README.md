# Meowgnificent the wizard cat — v0.2.0 / Accident Room

Extract the ZIP and launch the game. No installer, CMD command, or Godot installation is required.

- Windows: Meowgnificent-v0.2.0-windows.zip
- Linux x86_64: Meowgnificent-v0.2.0-linux.zip
- Web server build: Meowgnificent-v0.2.0-web.zip
- Godot source: Meowgnificent-v0.2.0-source.zip

Controls: WASD/arrows move; mouse aim; click/Space cast; Shift + direction roll; Enter start/retry; Esc pause; R restart. F1/F2/F3 force the next cast's success/miscast/overreaction.

Try rolling into a shelf, igniting one over an enemy, and turning a failed spell's panic roll into a belly attack. Watch enemy attack warnings and falling-shelf footprints. Fire hurts both sides.

This is one room for testing the comedy action direction, with three enemy roles, one spell, and interactive shelves/fire. It does not yet include a full run, additional spells, Chonk growth, bosses, or save progression.

See CHANGES.md for details. SHA-256 checksums are in Meowgnificent-v0.2.0-SHA256SUMS.txt. Previously shared anonymous file-host links are withdrawn.
