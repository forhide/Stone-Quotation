# Meowgnificent the wizard cat — v0.1.4

Download your platform ZIP, extract it, and run the game. No installer or terminal command is needed.

- Windows: Meowgnificent-v0.1.4-windows.zip
- Linux x86_64: Meowgnificent-v0.1.4-linux.zip
- Web server build: Meowgnificent-v0.1.4-web.zip
- Godot source: Meowgnificent-v0.1.4-source.zip

Changes: shorter, rounder torso; distinct miscast smoke, broken sparks, red X and FIZZLE! indicator. See CHANGES.md.

Controls: WASD/arrows to move; mouse aim; left click/Space cast; Enter start/retry; Esc pause; R restart.

Checksums: Meowgnificent-v0.1.4-SHA256SUMS.txt.

Previously shared temporary file-host links are withdrawn. Use this GitHub branch for downloads.
