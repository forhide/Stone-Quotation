# Meowgnificent the wizard cat — v0.5.0

An eight-area roguelite: six fights (including tutorial and final elite) and two shops. This version adds clear arrival/clear cards, an eight-stop route, distinct room materials, painted enemies and textured spell effects. Crowns and equipment belong to the current expedition; Starlight and purchased legacy upgrades survive defeat.

Download a ZIP below and extract it into a new folder. No installer or terminal download command is needed.

- [Meowgnificent-v0.5.0-windows.zip](Meowgnificent-v0.5.0-windows.zip)
- [Meowgnificent-v0.5.0-linux.zip](Meowgnificent-v0.5.0-linux.zip)
- [Meowgnificent-v0.5.0-macos.zip](Meowgnificent-v0.5.0-macos.zip)
- [Meowgnificent-v0.5.0-web.zip](Meowgnificent-v0.5.0-web.zip)
- [Meowgnificent-v0.5.0-source.zip](Meowgnificent-v0.5.0-source.zip)

Controls: WASD/arrows move, mouse aim, click/Space cast, Shift+direction roll, I equipment, E nearby merchant/open exit, Enter begin/next cleared area, M legacy studies from start/defeat/victory, Esc close/pause, R abandon. Shop/legacy: click or 1–4. F1/F2/F3 force the next spell outcome.

Validation:341 source checks;23 Windows/Wine executable checks;23 Linux executable checks;15 Chromium Web checks. Desktop checks cover tutorial combat, area02 arrival, loot/equipment, defeat and permanent progress in a fresh process. Full eight-area route is covered by source integration, not a full-campaign desktop bot. Mac package metadata, arm64, executable permissions and signature hashes passed; actual Mac launch and native Windows hardware performance were not tested. See CHANGES.md and the source ZIP QA evidence.

The Mac app is ad-hoc signed, not Apple-notarized. Read PLAY-MACOS.txt in the ZIP for normal macOS opening instructions. Anonymous file-host links remain withdrawn. SHA-256 values are in Meowgnificent-v0.5.0-SHA256SUMS.txt.
