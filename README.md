# Meowgnificent the wizard cat — v0.2.3

Proportions adjusted halfway toward the earlier, longer cat: a 6% narrower torso and approximately 16% longer torso. The face and hat keep their shape; feet remain anchored. Full-body poses and the v0.2.2 rendering optimizations remain.

Download and extract into a new folder, then launch the game. No installer or terminal command is needed.

- Windows: Meowgnificent-v0.2.3-windows.zip
- macOS / Apple Silicon support: Meowgnificent-v0.2.3-macos.zip
- Linux: Meowgnificent-v0.2.3-linux.zip
- Web server build: Meowgnificent-v0.2.3-web.zip
- Godot source: Meowgnificent-v0.2.3-source.zip

Controls: WASD/arrows move; mouse aim; click/Space cast; Shift + direction roll; Enter start/retry; Esc pause; R restart. F1/F2/F3 force the next spell result.

90 source checks and 10 Windows/Wine executable checks passed; Linux ZIP startup, Chromium Web smoke and Mac app/signature structure were checked. Actual Windows hardware and Mac runtime were not tested. The Mac app is ad-hoc signed and not Apple-notarized; see PLAY-MACOS.txt in the ZIP.

See CHANGES.md and Meowgnificent-v0.2.3-SHA256SUMS.txt. Previously shared anonymous file-host links remain withdrawn.
