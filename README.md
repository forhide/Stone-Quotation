# Meowgnificent the wizard cat — v0.9.0

The round orange wizard cat now walks with lower, calmer steps and a unified body/hat rhythm. Equipment expands from 9 to 36 pieces, with 12 distinct main-hand tools each supplying one manually activated special skill. Q or right-click uses the currently equipped skill; changing tools does not reset its remaining cooldown. Collars and hat charms shape movement, survival, spell and skill builds. The tutorial supplies a zero-stat practice wand. Fireball has a bright round hot core and an orange/red flame tail.

The story returns to the original user-provided storyboard: underground detention storage, synchronized library books, a grid of equal-height mushrooms, the failed-wizard friends and the Perfect Grimoire's attempt to remove uncertainty. Revised Korean and English follow the same events, and briefing art uses the same location and phenomena as the playable stage.

Korean is the default UI and story language. Settings / F10 switches Korean or English and saves the choice. The eight-area roguelite retains six fights, two shops and the final boss. Crowns and equipment belong to the current expedition; Starlight and purchased legacy upgrades survive defeat.

Download a ZIP, extract it into a new folder, and launch the executable/app. No MSI installer or CMD download command is needed.
