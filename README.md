# Meowgnificent the wizard cat — v0.10.0

The round orange wizard cat keeps its approved identity with six connected full-body walk poses and a hidden tail. Pip is consistently the same human merchant shown in the story. Combat HUD panels focus on the current stage, and the equipment window shows base/current character stats and the change produced by replacing a slot. Rounded pastel equipment/fire art, dedicated application icons and a redesigned Perfect Wizard with a clearer shield-break sequence complete this update.

Korean is the default UI and story language. Settings / F10 switches Korean or English and saves the choice. The eight-area roguelite retains six fights, two shops and the final boss. Crowns and equipment belong to the current expedition; Starlight and purchased legacy upgrades survive defeat.

Download a ZIP, extract it into a new folder, and launch the executable/app. No MSI installer or CMD download command is needed.
